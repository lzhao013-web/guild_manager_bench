Bench 如何运作

Guild Manager Bench 让模型在统一、可复现的回合制环境中独立经营公会，考察其 长期规划、资源分配与工具调用能力。

运行流程

  • 统一开局：模型使用相同的游戏 preset 与随机种子，从相同资源和规则开始。
  • 逐回合决策：模型在工具调用预算内查询信息、招募与培养冒险者、制作装备、购买升级，并提交讨伐目标。
  • 有限回合经营：每回合结束后世界刷新；模型持续积累资源并提升队伍终局战力。

评分与排名

  • 终局评分：系统固定评分种子，在多个竞技场难度下自动模拟最终队伍的战斗表现。
  • Rank Score：各难度贡献相加得到段位积分，高难度下表现更好的队伍得分更高。
  • 榜单聚合：同一模型的完成运行会被聚合，排行榜按平均 Rank Score 从高到低排序。

Rank Score（段位积分）

Rank Score 衡量冒险者队伍的综合战力。系统在从低到高的多个难度等级上模拟竞技场战斗：

单项贡献 = (战斗评分 ÷ 100) × 难度系数

最终得分 = 各难度等级贡献之和。队伍在高难度下表现越好，Rank Score 越高。 每位冒险者的贡献值和占比可在展开卡片后查看。

曲线对比面板展示每回合的 Rank Score 变化，反映队伍战力随培养进程的成长轨迹。
