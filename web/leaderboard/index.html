设计思路

Guild Manager Bench 是一个LLM Agent 长程决策能力评测基准。每个模型作为冒险者公会的管理者， 在有限回合内通过招募、训练、装备和战斗来培养队伍，最终以队伍战力接受排名。

评测设计

  • 模型在同一游戏种子下运行，保证公平可比
  • 每回合模型观察完整游戏状态，产出多步操作序列（行动、装备、训练等）
  • 考察的是长期规划而非单步最优：每一轮决策都会影响后续的资源积累和队伍成长
  • 终局通过多难度竞技场模拟评估队伍真实战力，而非简单结算数值

排序依据

  • 排行榜按 Rank Score（最佳） 降序排列
  • Rank Score 越高，代表模型培养的队伍在高难度战斗中胜率越高
  • 均值和中位 Rank Score 用于评估模型的稳定性
  • Arena Score（竞技场分）和游戏质量指标作为辅助参考

Rank Score（段位积分）

Rank Score 衡量冒险者队伍的综合战力。系统在从低到高的多个难度等级上模拟竞技场战斗：

单项贡献 = (战斗评分 ÷ 100) × 难度系数

最终得分 = 各难度等级贡献之和。队伍在高难度下表现越好，Rank Score 越高。 每位冒险者的贡献值和占比可在展开卡片后查看。

曲线对比面板展示每回合的 Rank Score 变化，反映队伍战力随培养进程的成长轨迹。
