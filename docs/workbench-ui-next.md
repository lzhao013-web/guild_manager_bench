# 工作台后续界面方案

状态：待确认，尚未实施。本文对应界面审查中的第 4、5、6 项。

第 1、2、3 项已另行落实：固定的可读字号与间距、历史列表压缩、曲线风险提示合并与共同回合定位。本文不调整评测规则、任务调度、存档格式或评分口径。

## 4. 单局观战：独立分配左右栏空间

### 推荐布局

保留当前模块和同工作区展开详情的方式，不增加新页面。

```text
运行身份、实时任务状态
当前观看位置、金币、经验、队伍、评分
┌─────────────────────┬───────────────────┐
│ 编队摘要             │ 最近行动           │
│ 人物、血蓝、等级      │ 操作、结果、资源变化 │
├─────────────────────┤                   │
│ 怪物摘要             ├───────────────────┤
│ 身份、阶级、更多入口  │ 两行模型摘要        │
├─────────────────────┴───────────────────┤
│ 装备摘要       招募摘要       公会发展     │
└─────────────────────────────────────────┘
回合、步骤、跟随控制
```

- 桌面左右栏建议约 58:42。左栏编队和怪物按内容占高，右栏把主要高度给最近行动，不再强制怪物和模型占用同一行的大面板。
- 模型摘要默认采用固定的紧凑高度。第一行显示本次调用状态和已报告用量，第二行显示最新正文或等待说明。等待、接收和完成不改变外部布局。点击进入已有完整模型模块。
- 最近行动突出最近一条有效操作，结果和资源变化分行显示。下面保留若干条操作，按可用空间限制条数，不使用大段单行省略文本承载结果。
- 装备、招募、公会发展保留在下方。没有可操作对象时显示简短原因和完整模块入口，不生成空列表。
- 小屏幕按编队、最近行动、怪物、模型摘要、经营摘要纵向排列。只使用页面滚动，总览卡片不再嵌套滚动。

### 交互约束

实时更新只更新内容，不自动交换模块位置，也不重置滚动。切换历史位置时，所有摘要继续共享同一快照。只展示日志中记录的模型正文、推理和操作结果，不生成额外解释。

### 取舍

不推荐本轮引入自由拖拽面板。拖拽虽然灵活，但会增加布局恢复、键盘操作和小屏幕适配成本。先通过稳定布局解决留白和截断。

验收重点：常见桌面尺寸下无重叠，模型持续输出时布局稳定，返回完整模块后仍保留原观看位置。

## 5. 运行中心与观战：主入口直接，停止与关闭分离

### 推荐入口

本项主要调整运行中心和观战面板。历史列表的次要操作收纳已包含在本轮实现中。

- 运行列表每行增加明确的“观战”按钮，直接进入该 run 的单局总览。模型名称仍打开侧栏详情，保留现有习惯。
- 多选后继续提供“观战选中”和“对比选中曲线”。单局入口不再要求先开侧栏，再找“专注查看”图标。
- 观战面板标题区保留关注、专注和关闭。关闭按钮的提示与无障碍名称统一为“关闭面板”，旁边说明关闭不会停止任务。
- 停止操作移入任务菜单底部，用分隔线和红色区分。单局底部也通过任务菜单提供停止，不与回看控制并排突出展示。

```text
运行行：模型与参数 | 状态 | 回合 | 评分 | 观战 | 更多
任务菜单：查看曲线 / 复制配置 / …… / 停止运行
面板标题：运行名称 | 关注 | 专注 | 任务菜单 | 关闭面板
```

### 停止确认

复用现有停止确认和服务端语义，确认窗口列出模型、种子和目标数量。运行中的任务说明将请求退出，阻塞超过 8 秒后可能强制结束，只能保证从最近成功检查点恢复。排队任务使用“取消排队”，不把两种状态都称为停止。

关闭面板、暂停跟随和定位历史不触发停止请求。已完成 run 不显示停止。返回列表或多路观战时保留原观看位置。

### 取舍

停止需要多一次打开菜单，换取与关闭面板的明确隔离。批量停止入口继续保留在选择工具栏，配合明确目标数量和确认，不额外增加全局紧急停止按钮。

验收重点：单局观战从运行行一次点击进入，键盘可操作菜单，关闭面板不会调用停止接口，确认取消不会修改任务。

## 6. 新建实验：连接来源先选，队列摘要常驻

### 推荐流程

保留单页弹窗，不改成逐步向导。已有用户可以快速修改参数，不必重复前进和返回。

每个模型先选择连接来源：

| 来源 | 默认展示 | 按需展示 |
| --- | --- | --- |
| 服务端默认 | 模型名称或“沿用服务端配置”说明 | 覆盖模型设置 |
| 已保存 API 配置 | 配置选择、接口摘要、模型选择 | 编辑连接 |
| 自定义连接 | 接口类型、地址、Key、模型名称 | 保存为 API 配置 |

- 首次默认使用服务端配置。选择已保存配置时，不把地址、Key 和保存配置表单全部铺开。
- 自定义连接的“保存为 API 配置”采用独立展开区域。保存配置是明确动作，不因加入队列自动保存密钥。继续沿用系统凭证库和模板不保存密钥的规则。
- 推理强度使用多选标签，提供“沿用默认”。多种接口同时参与时，只提供现有配置中共同支持的等级，不据此保证具体模型支持。导入模板中的不支持值应提示，不静默删除。
- 游戏种子仍允许批量粘贴，用可删除标签展示解析结果。重复次数旁继续说明不会自动改变种子。
- 高级参数继续默认折叠，字段含义和提交内容保持原样。

### 底部常驻确认区

```text
模型 × 推理强度 × 游戏种子 × 重复次数 = run 数量
[展开任务清单]                    [保存为模板] [加入队列]
```

- 任务数量随表单更新，空的强度或种子按现有默认组合解释。完整展开清单可在正文查看。
- 数量非法、超过单批次 64 个 run 或参数校验未通过时，显示原因并禁用提交。服务端待处理上限继续由现有接口校验，不根据前端旧数据承诺可用容量。
- 提交期间防止重复提交。失败保留表单，并在对应位置展示错误。
- 小屏幕底栏可换行，但不覆盖最后一项输入，弹窗标题和关闭入口保持可达。
- 续跑、指定回合分支重跑继续使用现有专用字段和版本风险确认，不套用新建实验的参数组合界面。

### 取舍

不推荐新增完整的多步向导。渐进展开能减少首次看到的字段，同时保留同屏比较多个模型、查看任务数量的能力。

验收重点：使用已有配置时无需展开连接字段，队列摘要在滚动中可见，默认值和模板往返不丢失，密钥与版本确认行为不回退。
